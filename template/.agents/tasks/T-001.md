## Objetivo

Crear o completar el README para que una persona nueva pueda entender el proyecto y ejecutar sus comprobaciones. Conservar la información útil existente.

## Alcance

- `README.md`.
- `scripts/check-readme.mjs`, comprobación sin dependencias externas.

## Fuera de alcance

- Código de producto, dependencias, configuración y reglas del bucle.
- Inventar comandos de arranque o características que el proyecto no tenga.

## Criterios de aceptación

- [ ] AC1: README.md explica el propósito y contiene los encabezados `## Requisitos`, `## Instalación` y `## Comprobaciones`.
- [ ] AC2: los comandos corresponden a archivos o herramientas del proyecto. Si no existe aplicación todavía, lo dice.
- [ ] AC3: `node scripts/check-readme.mjs` sale con 0 cuando están los tres encabezados y con 1 si falta cualquiera; el error nombra el encabezado ausente.
- [ ] AC4: la comprobación admite una ruta opcional como primer argumento para probar un README incompleto sin tocar el real. Si el archivo no existe, sale con 1 y un mensaje claro.

## Comprobaciones

El arquitecto añadirá antes de lanzar esta ficha a `gates`:

```json
{ "name": "README", "run": "node scripts/check-readme.mjs" }
```

Además del caso positivo, ejecuta el comprobador sobre un archivo temporal sin encabezados y comprueba que devuelve 1. Elimina solo ese archivo temporal al terminar.

## Notas para el ejecutor

Usa `node:fs` y UTF-8. Lee la información del repositorio; no incluyas rutas personales, credenciales ni datos privados. Es una tarea pequeña, sin cambios en producto.
